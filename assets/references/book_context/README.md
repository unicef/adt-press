# Book Context

Place book-specific context files here. These are used to provide the LLM with information about the specific book being processed.

## What to Include

- Chapter summaries
- Key themes and topics
- Vocabulary lists
- Character relationships
- Timeline of events

## File Naming

Use descriptive names that indicate the content:
- `book_summary.md` - Overall book summary
- `chapter_summaries.yaml` - Per-chapter summaries
- `vocabulary.yaml` - Key terms and definitions
- `themes.md` - Major themes and motifs
