# Activity Design Guidelines

## General Principles

### Engagement
- Activities should have clear, achievable goals
- Provide immediate feedback when possible
- Use varied activity types to maintain interest

### Accessibility
- Ensure activities are usable with screen readers
- Provide alternative text for all visual elements
- Use sufficient color contrast

### Cognitive Load
- Break complex tasks into smaller steps
- Limit the number of choices to reduce decision fatigue
- Use familiar interaction patterns

## Activity Types

### Matching Activities
- Limit to 4-6 pairs for younger learners
- Use clear visual distinction between items
- Provide audio support for text items

### Fill-in-the-Blank
- Provide word banks for younger learners
- Limit blanks to key vocabulary or concepts
- Ensure context clues are sufficient

### Multiple Choice
- Use 3-4 options maximum
- Avoid "all of the above" or "none of the above"
- Make distractors plausible but clearly incorrect

### Sorting Activities
- Use clear category labels
- Limit to 2-3 categories for younger learners
- Provide examples of correctly sorted items
