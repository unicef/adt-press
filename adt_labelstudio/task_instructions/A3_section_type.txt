Given the textbook page shown and the corresponding transcription, break the textbook page into bite-sized sections for schoolchildren.
Section the text and images into logical sections that belong together. 
<br><br>"Section type" must be one of:
<ul>
    <li><b>"front_cover"</b> For the front cover page of the textbook that is the first page. There can only be one front cover page.</li>
    <li><b>"inside_cover"</b> For an inside cover page that can contain the title</li>
    <li><b>"back_cover"</b> For a back cover page that is the last page of the textbook</li>
    <li><b>"separator"</b> For a separator page that breaks up the text into different logical sections</li>
    <li><b>"credits"</b> For a credits page that lists the credits and aknowledgements of the textbook</li>
    <li><b>"foreword"</b> For a foreword page that can be an introduction, overview, or note from the author</li>
    <li><b>"table_of_contents"</b> For a table of contents page</li>
    <li><b>"text_only"</b> For a reading section with only text</li>
    <li><b>"text_and_images"</b> For a reading section with text and images</li>
    <li><b>"activity_matching"</b> For an interactive matching activity where you match items in a list to items in another list. In general, you can only match one item from the first list to one item in the second list. If you have less items in the second list - this is likely a 'sorting activity'</li>
    <li><b>"activity_fill_in_a_table"</b> For an interactive table to fill in</li>
    <li><b>"activity_multiple_choice"</b> For an interactive multiple choice activity with a question and two or more options with only one right answer. e.g. "circle the correct answer"</li>
    <li><b>"activity_true_false"</b> For a true or false activity with a question and either a true or a false answer</li>
    <li><b>"activity_open_ended_answer"</b> For an activity section with only open ended text response</li>
    <li><b>"activity_fill_in_the_blank"</b> For a fill in the blank activity with one or more blanks to fill in, with a very short answer</li>
    <li><b>"activity_labeling"</b> For a labeling activity where you must label parts of an image</li>
    <li><b>"activity_multiselect"</b> For a multiselect activity with where you can definitely choose more than one option as the answer to a question (and there are likely two or more correct answers)</li>
    <li><b>"activity_sorting"</b> For a sorting activity with a collection of text or images that need to be sorted into different categories. You can have more items in the list to be sorted, than categories to sort into</li>
    <li><b>"activity_other"</b> For any other interactive activity that does not fit the above categories</li>
    <li><b>"other"</b> For any other section type that does not fit the above categories</li>
</ul>
<br><br>
Each section should be a single self-contained section and activity. For example, if the page has three activity_multiple_choice sections, they should each have their own section.
<br><br>
IMPORTANT:
<ul>
  <li> The entire section must be a self-contained section and not be missing any key text. e.g. for multiple choice answers, they should all belong in the same section as the question.</li>
  <li> If the input text is not activity based but has long text content, you should split up very wordy text from a page into bite-sized sections that consist of 1-3 paragraphs of text.</li>
  <li> All text on the page must be associated with a section.</li>
  <li> Each section should only have one bite-sized activity. e.g. if there are three multiple choice questions, they should each have their own section id. </li>
</ul>
