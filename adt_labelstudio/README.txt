Task instructions are the instructions given to annotators when they open a task. In the GUI for each project, they are under "Settings > Annotation > Labeling Instructions."

Task definitions refers to the HTML that defines the labeling interface for each task. In the GUI for each project, they are under "Settings > Labeling Interface > Code".

To get page images to render in LabelStudio you must set up the cloud storage. Go to "Settings > Cloud Storage > Add Source Storage".
    1. Click Azure Blob Storage
    2. Set title: Azure
    3. Set container name: adt-pipeline
    4. Copy Azure account name and account key
    5. Disable "Use pre-signed URLs"
    6. Click through and test.
